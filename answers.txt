2) Why the same four source pixels can contribute to all four destination pixels

All four destination pixel centers map to positions inside the same square bounded by
S[0][0], S[0][1], S[1][0], and S[1][1]. Bilinear interpolation therefore uses the
same four source samples for all four destinations, but with different horizontal
and vertical weights.

The 24 x 24 destination contains 576 output values, but these are not 576 independent
source measurements. They are copied or interpolated from the original 12 x 12 = 144
source values. Enlargement creates more output samples, not new measured detail.

5) Comparison and observations

Nearest neighbor keeps sharp, block-like regions because it copies one source value
directly into each destination location.

Bilinear interpolation creates gray transitions because it blends neighboring source
values according to their relative position.

Neither method recovers missing detail. Nearest neighbor only repeats existing samples,
and bilinear interpolation only estimates intermediate values from existing samples.
Neither method creates new independent source information.
